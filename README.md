# Miguel Ángel Leo Acedo
**Data & IA aplicada a farmacia** · Creador de SmartPharma

Más de cinco años trabajando en farmacia como técnico me enseñaron dónde se pierde el dinero:
stock parado, roturas, compras y precios decididos sin mirar los datos. Hoy convierto esos
datos en decisiones de negocio con Python, SQL e IA.

## Qué hago
- **Análisis de datos de negocio** — ventas, márgenes, rentabilidad y rotación por
  laboratorio, estacionalidad, impacto de promociones.
- **Optimización de stock y compras** — predicción de demanda, stock de seguridad, pedidos
  transfer con tramos de descuento.
- **Agentes de IA sobre datos sanitarios** — agentes que cruzan APIs públicas (FDA,
  ClinicalTrials.gov) con pandas y LLMs para responder preguntas de negocio.

## Proyectos destacados
- **[SmartPharma](https://github.com/elmonoobeso/SmartPharma)** — Herramienta de análisis de
  negocio, stock y predicción de demanda para farmacias, en piloto con una farmacia real.
  Python · pandas · Streamlit · XGBoost
- **[LEARNING-PROCESS](https://github.com/elmonoobeso/LEARNING-PROCESS)** — Aprendizaje en
  público: de fundamentos de Python a agentes LLM (retiradas de la FDA, huecos terapéuticos
  en biosimilares con LangGraph), con errores y decisiones documentados.
